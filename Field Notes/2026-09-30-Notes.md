# Session 1

**10/1/26 / 8:00pm / location: Homelab**

**What I'm doing today:** Building the basic groundwork for the project and collecting the first sound samples from malware captures.

**Setup:** Kali VM in UTM. Two mappings so far, forest and coastal, both using synthesized sounds for now.

## Workflow

- Downloaded a capture from malware-traffic-analysis.net.
- Briefly analyzed the pcap to find the victim machine (needed its IP for the next step).
- Ran the script to convert the pcap to a soundscape.
- Command:
  ```
  python3 netscape.py ~/malware-pcaps/2026-02-28-traffic-analysis-exercise.pcap -m mappings/forest.json -o malware02_forest.wav --target 10.2.28.2 --speed=15
  ```
- Flags:
  - `-m` chooses the mapping
  - `-o` names the output file
  - `--target` is the victim IP (its outgoing traffic plays on the right, incoming plays on the left)
  - `--speed` compresses the 20+ minute capture to avoid the out-of-memory error my current setup throws due to length of most captures.

## Decisions

- Used premade captures instead of generating my own attacks. Wanted to test on real-world malware traffic.
- Set `--target` to the victim so the infected machine's direction is audible in the stereo field.
- Used `--speed 15` because real-time renders ran out of memory. This speed feels a little bit too fast and skews sound. 
- With these initial samples, I mapped both samples to both soundscapes.
