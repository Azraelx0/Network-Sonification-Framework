# Session 1
In this session, I built the basic groundwork for my project and collected several samples.

basic workflow:
- download a malware sample from malware-traffic-analysis.net
- briefly analyze the pcap to figure out the victim machine (need its IP for next part)
- run my script which converts the pcap to a soundscape mapping, so far only two mappings (forest and coastal), and both are synthetic for now
- command to run script:
```
python3 netscape.py ~/malware-pcaps/2026-02-28-traffic-analysis-exercise.pcap -m mappings/forest.json -o malware02_forest.wav --target 10.2.28.2 --speed=15
```
- note that we just take the pcap file, use -m to choose which soundscape to map our pcap to, -o to designate the output file
- --target for the victim's IP (Important because everything the infected machine sends, including beaconing to its c2 server, plays on the right, and everything it receives plays on the left.)
- --speed is to speed up the clip as these captures can span 20+ min which leads to errors, at least with my current setup.
